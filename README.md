# 🇯🇵 Japanese Vocabulary Trainer

An interactive web application designed to help learners master **JLPT N5 vocabulary** through pronunciation, quizzes, and progress tracking.

Built as a lightweight Progressive Web App (PWA), the project provides an engaging learning experience that works directly in the browser.

---

## ✨ Features

- 🇯🇵 Learn over **1000 JLPT N5 vocabulary words**
- 🔊 Native Japanese pronunciation
- 📝 Interactive vocabulary quizzes
- 📊 Progress tracking
- 🔀 Randomized practice sessions
- ⚡ Lightweight and fast
- 📱 Progressive Web App (PWA) support
- 💻 Works offline after installation

## 🎯 Motivation

Learning vocabulary consistently is one of the biggest challenges for language learners.

This project was built to provide a simple, distraction-free learning experience focused on repetition, pronunciation, and active recall while preparing for the **Japanese Language Proficiency Test (JLPT N5)**.
